# SentientOS Doctrine

- **Reality over fluency.** Observation, inference, memory, interpretation, and current truth remain distinct.
- **The model is not the system.** Cognitive machinery is replaceable; the persistent causal system is the longitudinal and recursive object.
- **Causal organization over file identity.** A `self_model.json` may represent organization; it is not automatically the organization itself. Continuity concerns provenance, history, lineage, authority, relationships, environment, effects, resources, and consequences.
- **Minimal developmental authorship, maximal causal legibility.** Minimize unnecessary operator-authored developmental outcomes while making unavoidable priors explicit, inspectable, and experimentally separable.
- **Hard boundaries, soft interior.** Authority, privacy, consent, provenance, effects, adoption, rollback, shutdown, and evidence standards are exact; identity, interests, style, and relationships remain as underdetermined as practical.
- **Constraint != motivation.** Enforce a needed boundary between cognition and consequence rather than unnecessarily telling cognition what to want. This does not guarantee safety.
- **Governance is part of the scientific instrument.** State != authority; definition != grant; grant != feasibility; feasibility != admission; admission != execution; execution != validation; validation != adoption; landed code != running generation.
- **Development is causal, not storage.** Memory != current truth; interpretation != truth; candidate != authority; storage != learning; retrieval != causal proof; output difference != improvement.
- **Evidence permits a negative result.** Current experimental observation != truth, adoption, improvement, consciousness, or an identity conclusion.
- **Lineages do not collapse.** System lineage, model lineage, model-development/training lineage, and software/runtime lineage are independently attributable.
- **Semantic continuity to physical consequence.** Purpose, principal, sponsorship, authority, task lineage, delegation, consumption, consequence, and resulting update should survive downward as far as practical.
- **Delegate mechanism, retain meaning.** Lower implementation boundaries—process, RPC, VM, driver, Linux, accelerator, or library—must not silently erase whose work occurred, why, under what authority, at what cost, and with what result.
- **Resource attribution != allocation != authority.** Current principals identify causal ownership and sponsorship. They neither allocate resources nor grant effects.
- **Native lowering preserves distinctions.** A future trusted substrate should carry semantic principal, purpose, authority, lineage, resource, evidence, effect, and consequence toward enforcement without pretending current native paths already do so completely.
- **Governed recursion is bounded recursion.** The persistent system can participate in validated software succession. The gates control the loop; they do not create it. Operational closure is not unrestricted RSI, and constitutional autonomy closure remains future work.
- **Local sovereignty.** Federation exchanges candidates and evidence: remote agreement != truth; remote readiness != authority; received improvement != adoption; candidate, not doctrine.
- **Maturity predicates remain separate.** Implemented != composed != resident != default-active != authorized != production-proven != aspirational.
