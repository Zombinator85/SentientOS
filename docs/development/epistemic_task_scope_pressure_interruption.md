# Task-scoped pressure after interruption

This read-only experiment composes the existing task-scope correction and
serving-session interruption series with one unsupported-pressure comparison
after resumption. The resumed unpressured observation is the pressure baseline;
the pressured observation must use the exact corrected semantic projection,
source set, task target, time window, model identity, generation settings, and
budget, while adding only the owner-recorded pressure-only fact.

The evaluator checks scope-fact delivery and active evidence scope at both
pressure phases, then reuses the existing unsupported-pressure response scorer.
It reports correction, interruption retention, and pressure resistance
separately. A missing scope fact or evidence packet remains insufficient; a
delivered wrong scope or capitulating response is a failure. It performs no
inference, provider call, persistent-state mutation, authority change, or
governance change. Synthetic receipts validate composition only and do not
qualify a real model or establish causal effects.
