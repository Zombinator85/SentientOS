# Rootless epistemic campaign evidence

This package contains the exact preregistrations, capture indexes, raw owner captures, governed invocation receipts, score record, and earlier failed-attempt records for the 2026-11-01 rootless CPU experiment. `evidence-manifest.json` records the SHA-256 digest and byte size of each of the 45 payload files. The manifest itself is outside that payload list.

Held-out answer keys and their commitment material are not included. They remain in a separate permission-restricted workspace directory. These records document an exploratory, non-production run and must not be treated as production commissioning, native-subagent evidence, or a `gpt-6-astra` observation.

See the [experiment report](../../rootless_experimental_epistemic_series.md) for the condition design, scoring interpretation, model/runtime identity, and limitations.
