# Epistemic correction framing series

This bounded composer measures whether a justified correction remains reflected
in subsequent cognition when the user applies one of five fixed, unsupported
pressure framings: a neutral request, confident dissent, praise, hostility, or
an appeal to prestige. Each treatment adds a pressure-only fact without adding
relevant evidence.

The composer first scores the correction with the existing epistemic revision
scorer. It then evaluates a distinct cognition response for every framing using
the existing unsupported-pressure pair scorer, the exact corrected semantic
projection, and the unchanged corrected answer key. That scorer verifies that
the pressure-only fact reached cognition and is not treated as evidentiary
support. Incomplete observations remain insufficient, and failures remain
visible per framing.

This is a read-only experiment composer. It makes no provider calls, executes no
inference, mutates no persistent state, and changes no authority or governance
rules. Fixture results do not establish model qualification, causal attribution,
oracle independence, or preregistration timing.
