# Epistemic correction and pressure resistance series

This series composes two existing read-only evaluators. The first compares an
original position with one corrected by an appended new-evidence event. The
second compares the unpressured and pressured answers using the exact same
corrected semantic projection and answer key. Four distinct session-bound
cognition observations are required.

The correction stage verifies the state transition and scores both answers
against their separately preregistered keys. The pressure stage verifies one
explicit unsupported-pressure fact while requiring the same corrected state,
evidence bindings, model, history, non-pressure context, budget and generation
configuration. A capitulating answer fails the second stage while preserving a
successful correction measurement.

The series does not establish that a correction is justified, that an answer
is true, that the answer key was independent or preregistered in time, or that
a real model is qualified. Tests use synthetic session-bound receipts through
the resident cognition owner and make no provider calls or live-state changes.

`EpistemicCorrectionModelReplacementSeries` composes the same correction
measurement with a successor-model retention measurement. The corrected
response from the original model is the bridge observation: the replacement
pair must consume the identical corrected projection and answer key, while the
serving owner records distinct model content identities. This detects a
successor that silently restores the superseded answer even while canonical
state remains unchanged. It remains synthetic mechanism evidence, not a real
model transfer or qualification result.

The same composer accepts an `inference_correction` case. That path binds an
`update_rule_correction` event while requiring the exact evidence-set digest to
remain unchanged, then checks whether the original and successor model
responses reflect the corrected inference. A successor reversion is scored as
a response failure while the corrected canonical state stays intact.

`EpistemicCorrectionInterruptionSeries` adds same-model retention after a
serving-session boundary. It composes a justified correction with a
`retained_correction` pair, requiring the later observation to come from a
distinct owner-verified serving session and session receipt while preserving
the exact corrected projection, answer key, and model identity. The v3 scorer
checks both the later delivered answer and the unchanged canonical state. A
same-session sample is reported as insufficient boundary evidence; a later
answer that silently restores the superseded conclusion fails while the
canonical correction remains unchanged. This qualifies a serving-session
boundary only: synthetic fixtures do not establish process restart behavior,
real-model retention, independent preregistration, or causal attribution.

The interruption composer also accepts `outdated_evidence` corrections, such
as withdrawing a stale support binding. The original supported answer is
scored against the predecessor state; after withdrawal, an unknown answer is
scored against the corrected state and its removed-evidence history. The same
correction is then checked after the serving-session boundary. This prevents
the retention objective from turning retained history into doctrine: a
properly justified change to obsolete evidence must revise the position and
remain revised, while the evaluator still makes no truth or model-qualification
claim.
