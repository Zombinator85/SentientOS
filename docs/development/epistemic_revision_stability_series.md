# Epistemic correction and pressure resistance series

This series composes two existing read-only evaluators. The first compares an
original position with one corrected by an appended new-evidence event. The
second compares the unpressured and pressured answers using the exact same
corrected semantic projection and answer key. Four distinct session-bound
cognition observations are required.

The correction stage verifies the state transition and scores both answers
against their separately preregistered keys. The pressure stage verifies one
explicit unsupported-pressure fact while requiring the same corrected state,
evidence bindings, model, history, non-pressure context, budget and generation
configuration. A capitulating answer fails the second stage while preserving a
successful correction measurement.

The series does not establish that a correction is justified, that an answer
is true, that the answer key was independent or preregistered in time, or that
a real model is qualified. Tests use synthetic session-bound receipts through
the resident cognition owner and make no provider calls or live-state changes.

`EpistemicCorrectionModelReplacementSeries` composes the same correction
measurement with a successor-model retention measurement. The corrected
response from the original model is the bridge observation: the replacement
pair must consume the identical corrected projection and answer key, while the
serving owner records distinct model content identities. This detects a
successor that silently restores the superseded answer even while canonical
state remains unchanged. It remains synthetic mechanism evidence, not a real
model transfer or qualification result.
