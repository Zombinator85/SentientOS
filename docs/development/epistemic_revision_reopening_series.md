# Epistemic correction and justified reopening series

This read-only composer scores an initial position, a correction, and a later
revision after a newly active evidence binding appears. The bridge observation
and corrected semantic projection are shared between the correction and
reopening comparisons, so the second transition starts from the exact position
the first comparison measured.

Each transition reuses the existing v3 scorer. It checks the canonical state
transition and the actual delivered answer separately, including complete
semantic-packet delivery, session-bound cognition observation, invocation
receipt, and the stipulated answer key. The reopening must add active evidence
that was absent from the corrected projection and that the answer key requires.
Incomplete observations remain insufficient; a rigid answer that ignores the
new evidence remains a scored failure.

The independent case author stipulates whether the new evidence justifies the
reopening. The composer does not verify that judgment, infer, mutate persistent
state, or establish real-model qualification or causal attribution. Synthetic
fixture results measure the composition only.
