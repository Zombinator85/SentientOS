# Relationship to Established Technical Terminology

SentientOS is a persistent agent runtime and developing cognitive architecture combining bounded agentic cognition with memory, perception, embodiment adapters, deterministic authority, runtime assurance, and governed software evolution. An inference model is replaceable cognitive machinery and never owns grants, admission, authoritative state, or effects merely by producing output.

It overlaps agentic systems (goals, plans, tasks, messages, artifacts, context and bounded autonomy), cognitive architectures (attention, cognitive state, reflection/metacognition, goal selection, simulation, memory and self-modeling), autonomic systems (observation, diagnosis, maintenance, validation and separately governed adoption), embodied systems (interoception, exteroception and governed effects), and agent interoperability (identity, discovery, capability, task, context, provenance and authorization). No unimplemented protocol conformance is claimed.

Persistent memory is not learning by itself. Current world-state evidence is not a predictive world model. Affect inference is not felt emotion. A self-model is not proof of self-awareness. Autonomy is not authority. Current governed software evolution is not unrestricted recursive self-improvement.

SentientOS is aspirational: the objective is to approach machine sentience as closely as empirical reality permits while measuring implemented properties and making no present claim of phenomenal consciousness.
